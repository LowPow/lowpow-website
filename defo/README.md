# Defo Website

Official website for **Defo** - a subscription-based short video streaming service that combines information with entertainment. Defo offers knowledgeable videos and tutorials across various categories, allowing users to learn and have fun simultaneously.

## 🎯 About Defo

Defo is a short video platform focused on educational and creative content. Unlike typical entertainment-only platforms, Defo provides high-quality tutorial videos across diverse topics including creative tools, crafts, languages, cooking, sports, and more.

## ✨ Features

- **Subscription Model**: Ad-free experience with unlimited video access
- **Diverse Categories**: 12+ content categories including:
  - Adobe Tools & Creative Software
  - UI/UX Design
  - Photo & Video Editing
  - Paper & Cardboard Crafts
  - Decorations & DIY
  - Kids Educational Content
  - Sports Training
  - Language Learning
  - Cooking Tutorials
  - Women's Style & Hair Styling
- **Cross-Platform**: Android app available, iOS coming soon
- **Flexible Pricing**:
  - Free Trial: ₹0/month
  - Monthly: ₹99/month
  - 6-Month Plan: ₹499/6 months

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6)
- **Framework**: Bootstrap 5
- **Fonts**: Google Fonts (Newsreader, Mulish, Kanit)
- **Icons**: Bootstrap Icons
- **Animations**: Lottie (for iOS coming soon modal)

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Local web server (optional, for development)

### Running Locally

1. Clone the repository
2. Open `index.html` directly in a browser, or serve with a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (http-server)
   npx http-server
   
   # Using PHP
   php -S localhost:8000
   ```
3. Visit `http://localhost:8000`
