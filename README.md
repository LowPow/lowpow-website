# LowPow Websites

This repository contains the marketing websites for all LowPow apps and products.

## Projects

### [lowpow/](lowpow/) - Main Company Website
**Live:** [https://lowpow.dev](https://lowpow.dev)

The main LowPow Technologies website showcasing all apps and company information.

- **Stack:** HTML5, CSS (Bootstrap), JavaScript (Vanilla + Swiper)
- **Features:** App showcase, testimonials, founder profiles, contact/social links
- **Pages:** Home, About, Terms, Privacy

### [defo/](defo/) - Defo Website
**Live:** [https://defo.lowpow.dev](https://defo.lowpow.dev)

Marketing site for Defo - a subscription-based short video streaming app for infotainment content.

- **Stack:** HTML5, CSS (Bootstrap + custom theme), JavaScript
- **Features:** Category showcase, pricing tiers, download badges, feedback form
- **Pages:** Home, Legal (Privacy, Terms)

### [lugardev/](lugardev/) - Lugar Website
**Live:** [https://lugardev.com](https://lugardev.com)

Website for Lugar apps including StickBook and Digitalize.

- **Stack:** HTML5, SCSS (compiled to CSS), JavaScript (Bootstrap + GLightbox)
- **Build:** `npm run build` (compiles SCSS)
- **Features:** App showcase, testimonials carousel, app store links
- **Pages:** Single-page layout with sections

### [stickbook/](stickbook/) - StickBook Website
**Live:** [https://lowpow.dev/stickbook/](https://lowpow.dev/stickbook/)

Marketing site for StickBook - Tamil stickers app for WhatsApp with meme templates.

- **Stack:** HTML5, CSS (custom + vendor), JavaScript (jQuery + plugins)
- **Features:** Sticker pack showcase, how-to guide, testimonials, download links
- **Pages:** Single-page layout with smooth scroll sections

### [vadistick/](vadistick/) - VadiStick Website
**Status:** Under Construction

Coming soon page for VadiStick - Vadivelu stickers for WhatsApp.

- **Stack:** HTML5, CSS (inline), JavaScript (particles.js)
- **Features:** Animated particles background, progress indicator

### [TamStick.md](TamStick.md) - TamStick Documentation
Documentation for the TamStick app website (hosted separately at tamstick.lowpow.dev).

- **Stack:** HTML5, SCSS, JavaScript (jQuery), Firebase Hosting
- **Deploy:** `firebase deploy --only hosting:tamstick`

## Quick Start

Each project is a standalone static site. Open any `index.html` directly in a browser, or serve with a local server:

```bash
# Example: serve the main lowpow site
cd lowpow
npx serve .

# Example: build and serve lugardev
cd lugardev
npm install
npm run build
npx serve .
```
