# StickBook - Tamil Stickers for WhatsApp

A responsive promotional website for **StickBook**, a Tamil sticker app for WhatsApp featuring meme templates, trending stickers, and animated packs.

## Overview

StickBook is a mobile app that provides Tamil-language stickers for WhatsApp, including:
- **Trending packs**: GP Muthu, Parithabangal, BTS, Uruttu, Cook With Comali
- **Meme packs**: Dank Memes, Doge
- **Popular packs**: Web Series, Singamuthu, Babies, Heart
- **Animated stickers**: Kitties, Cook with Comali

## Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Modular stylesheets (base, vendor, main)
- **JavaScript** - Vanilla JS with jQuery 3.2.1
- **Libraries**:
  - Modernizr - Feature detection
  - Pace.js - Page load progress bar
  - Slick Slider - Carousel/slider functionality
  - Font Awesome & Custom Icons (micons)

## Features

- **Hero section** with parallax background and app screenshots
- **About section** showcasing sticker pack categories via slider
- **How-to guide** for adding stickers to WhatsApp (4-step process)
- **Testimonials** carousel with user reviews
- **Download section** with Google Play Store link
- **Responsive design** with mobile-first approach
- **Smooth scrolling** navigation
- **AOS (Animate On Scroll)** animations
