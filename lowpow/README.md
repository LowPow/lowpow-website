**LowPow** — an app development company with the mission of building the best apps for users.

## Overview

- **Type:** Static HTML/CSS/JS website
- **Year:** © 2026

## Tech Stack

- **HTML5** — Semantic markup
- **Bootstrap 5** — Responsive CSS framework
- **Font Awesome** — Icon library
- **Swiper** — Image and text sliders/carousels
- **Custom CSS & JavaScript** — Styling and interactivity
- **Google Fonts (Open Sans)** — Typography

## Features

- Responsive design (mobile-first with Bootstrap 5)
- Fixed navigation with collapsible mobile navbar
- Product/service cards with images
- Testimonials section with user feedback
- Founder/team profiles
- Social media integration with Font Awesome icons
- Back-to-top button
- SEO meta tags and Open Graph tags
- Swiper-powered sliders (card slider, image slider)
